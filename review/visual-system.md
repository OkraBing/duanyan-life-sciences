# 简约视觉规范

2026-11-21，按用户“配色过于花哨，希望更简约”的要求更新。布局、控件尺寸及业务行为继续使用当前版本；本规范覆盖此前对装饰色、按钮 hover 色和目录封面的约定。

| 用途 | 浅色主题 | 规则 |
| --- | --- | --- |
| 页面／卡片 | `#F8F9FA`／`#FFFFFF` | 中性底色，依靠间距和细边框分层；卡片不加装饰阴影。 |
| 正文／辅助文字 | `#171A1F`／`#59616D` | 同级标题同色；文件类型、任务类型和普通图标不再各用一套颜色。 |
| 交互强调 | `#3B5F9B`，浅底 `#F0F3F8` | 低饱和蓝用于链接、选中、焦点和进行中标记。主按钮使用深灰，hover 仍保持中性。 |
| 成功／异常 | `#336950`／`#B34236` | 实验页仅异常标签保留红色；正常进行中、有结论和草稿使用中性文字。其他模块按需保留紧凑状态提示。 |
| 分类／成员／待审批 | 中性色 | 移除紫色分类、黄色审批底块、项目彩色侧条。共享标签及管理共享入口保留克制的蓝色。 |
| 实验进度 | 完成灰色实线，当前环节灰色描边 | 不使用红绿蓝混排；卡片边框、说明与结论区域保持中性，hover 统一灰色。 |
| 图形 | 目录封面为单色预览 | 结构详情和科研图表的 pLDDT 等科学配色继续保留，未对页面整体使用滤镜。 |

深色主题使用对应的中性表面与降低饱和度的强调色。文字与焦点分别按 4.5:1、3:1 检查对比度；禁用状态沿用既有交互组件规则。

主题颜色的来源是 `src/index.html` 顶部三个主题声明（默认、系统深色、显式深色）；组件使用色的规则集中在 `src/visual-system.css`。`--wet` 兼容旧组件名称，已映射为中性色，不再表示第二套紫色主题。

项目卡片补充约定：个人与共享项目在桌面使用相同的两列网格和 20px 内边距，窄屏切为一列；不生成左侧装饰条。状态使用右上角中性标签，标题最多两行，说明保持两行高度，底部统计与操作分区。副本按钮独立于整卡入口，窄屏不能偏出卡片或遮住资源数量；页头在窄屏分为标题、搜索与新建两行。

`npm run test:visual-style` 检查深浅主题、18 个页面、文字对比度、普通标签与图标、目录预览与科研色标、实验和工作台状态、按钮 hover、键盘焦点及系统主题回退。脚本不调用真实模型、实验设备或第三方写入；截图和结果输出到 `work/qa/visual-simplification/`。

实验页最新配色约定（2026-11-21）：移除异常卡片红色侧边、绿色结论装饰、蓝色状态筛选和大块红底；“异常”标签使用少量红色，其他状态保留文字并使用灰色。完成环节为灰色实线，当前／异常环节为中性描边，未开始为浅灰。详情流程节点、共享实验时间线和工作台状态同步收敛；键盘焦点与科学数据色标保留。

筛选器样式补充（2026-11-21）：以用户指定的生命科学工具页胶囊筛选为基准。分类筛选复用 `.pill`，选中使用深灰底白字，未选中使用浅灰底和细边框；不再按用途切换其他强调色。桌面同为 32px 高，触屏为 44px，较窄时保留完整标签并换行。下划线页签继续表达页面分栏。筛选器的选中、hover 和键盘焦点分别表达，深浅主题均保持文字对比度。
