# 交互组件对照约定

基准：`5a38eb6`（新增工作台、共享项目和蛋白实验页面之前的版本），对照项目管理、项目对话、模型列表、新建训练和新建数据集。先测量旧版实际呈现，再对齐新增页面；不另建视觉体系。

| 组件 | 对照结果与本轮处理 |
| --- | --- |
| 主按钮 | 沿用项目管理的深色底、8px 圆角、桌面 30px 高、12.5px 字号；今日灵感的“去探索”按最新要求使用次要文字操作，降低视觉权重。 |
| 表单 | 旧版单行输入为 32px，新页面曾混用 42px 输入与 32px 下拉；统一桌面单行输入和下拉为 32px、8px 圆角、13.5px。多行内容单独保留高度，窄屏单行控件为 40px。筛选条继续使用既定 32px 档。 |
| 页签 | 共享页顶部沿用模型列表的文字加下划线：13.5px、约 35.6px 高、深色选中文字与蓝色下划线。资产侧栏继续沿用项目对话的页签。 |
| 菜单 | 继续复用旧版 `menu()`，保留方向键、Home/End、Esc 返回及禁用项。可见下拉按钮继承错误说明与无效状态；有效选项会清除错误。 |
| 选择卡片 | 选择保持浅蓝底，hover、键盘焦点与禁用分开表达；不改变选项数据或业务含义。 |
| 关闭 | 抽屉共用 15px SVG 关闭图标，桌面 28px 点击区域、窄屏 44px；关闭采用中性色，删除仍用红色。 |
| 弹窗与抽屉 | 复用现有弹窗框架、校验和操作栏。共享节点仍为非模态右侧抽屉，Esc 返回节点焦点，保留画布位置；不将不同场景强行改成同一种容器。 |
| 项目与状态卡片 | 项目／共享项目沿用已统一的卡片。异常实验 hover 保留红色，正常进行中保留蓝色，有结论保留绿色与文字；不改变卡片尺寸。 |

文案沿用 `tricky20-plan.md` 的策略：对象、动作名称统一，正文只留当前操作需要的信息。LabOS 的实验运行、设备接入等业务调整仍待用户确认，不属于本轮组件修改。

`npm run test:components` 覆盖 12 组跨页面检查：深浅主题与 hover、表单几何、弹窗稳定、多行输入、可见下拉校验、菜单键盘、选择卡片、页签、抽屉焦点与画布、关闭与删除颜色、异常 hover、窄屏及固定操作栏。专项已接入 `npm run test:requirements` 与默认回归。截图、实际测量和结果写入 `work/qa/interaction-components/`。
