# 20 轮审查策略与范围

本轮继续执行用户最后一次同类要求，逐项对照 `requirements-20261120.json` 的 63 条需求。旧 A/B/C、任务 tab、统计条、英文眉题和开发说明不恢复。

产品定位：给蛋白研究员在桌面反复查看课题、配置实验、选择设备、共享和复用科研资产的工作平台。

用户三问：现在进行到哪里？下一步能操作什么？哪些内容可被获取和复用？语气保持直接、平实；正文只留完成当前操作所需信息，详细条件放详情，动作交给控件。科学型号、SOP、API Key 和论文原题保留。对象词统一为课题、实验、环节、设备、资产版本；动作使用去探索、申请获取、确认导入、共享资产、创建项目副本。

视觉基准来自当前项目管理和项目对话页面：黑白浅灰、克制蓝色；同级标题 28px、卡片圆角 12px；正文 13–14px，桌面辅助信息以 12px 为主；图标沿用线性 SVG，状态同时使用颜色和文字。移动端按空间调整字号与布局，不强行套用原生移动端尺寸规则。
