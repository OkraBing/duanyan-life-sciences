# 新增功能走查用例

用例以当前需求为准。执行入口：`npm run test:requirements`、`npm run test:tricky20`、`npm run test:new-pages`。每次运行使用隔离浏览器数据；步骤中的用户、项目与资产均为测试记录。

## 工作台与科研对话

| 编号 | 操作路径 | 预期与数据核对 |
| --- | --- | --- |
| WB01 | 默认进入工作台；切换课题窗口 | 课题名称与项目 ID 一致；每张课题卡同时有实验、模型任务，各最多三条；组内没有分页或滑动控件 |
| WB02 | 查看超出三条的课题；分别点击查看全部 | 余量等于关注任务总数减三；进入相应实验管理／模型制备模块，保持同一项目范围 |
| WB03 | 逐条打开实验、训练、评测和推理任务 | 进入对应记录详情；任务 ID、项目 ID、状态与进度一致；任务名和特殊字符原样显示 |
| WB04 | 打开完成未查看任务；返回并重载 | 该结果从关注列表退出，完整列表保留；运行中、异常记录不会因查看而被消除 |
| WB05 | 重跑已查看任务；改变结果版本；另开旧标签页 | 新结果重新出现；旧页面不能清除新版本已读状态；重命名不等于新结果 |
| WB06 | 刷新灵感；重载；点击去探索 | 同日保持手动刷新后的问题；绑定正确课题，输入框可编辑，不自动发送 |
| WB07 | 查看四张论文；前后翻页；打开每篇原文 | 每页最多四篇，首尾禁用，手动切换；每张包含标题、摘要描述、相关课题和 HTTPS 外链 |
| WB08 | 注入截图中的无关论文缓存；重新进入和重载 | 教育、思政、非遗等记录不显示且清理缓存；未知中文关键词不能放行全部论文 |
| WB09 | 返回混合学科检索结果；使接口失败 | 生命科学主题与课题匹配分别校验；不把 CRISPR 检测直接标为 SNase 课题结果；失败保留可用论文，不编造摘要 |

## 设备与实验

| 编号 | 操作路径 | 预期与数据核对 |
| --- | --- | --- |
| DV01 | 遍历设备类型；按名称、型号、能力搜索；输入无结果词 | 筛选状态明确；结果正确，清空后恢复；无结果不误报没有设备 |
| DV02 | 鼠标和键盘打开全部设备详情；查看厂商资料 | 名称、型号、环节、输入输出对应同一设备；链接安全；整卡可进入 |
| DV03 | 空申请、填写后取消、重新申请并重载 | 空实例有错误提示；取消不保存；有效申请保持申请中，说明与实例对应 |
| DV04 | 申请中进入详情；未核对即确认；勾选后确认 | 未勾选不变为已接入；确认后持久化；普通查看不自动完成接入 |
| EX01 | 按课题和状态筛选实验；点击记录 | 列表、计数、详情属于同一项目；正常、异常、有结论、草稿区分正确 |
| EX02 | 遍历三种模板、全部操作、串行与并行分支 | 前置依赖、设备推荐和输入输出随环节变化；不同环节不串用实例或 SOP |
| EX03 | 用定位图与左右箭头编辑；切换执行关系后返回 | 输入值保持；选中节点、表单标题和焦点一致；当前位置可见 |
| EX04 | 不填必填项直接创建；逐项修正；保存草稿 | 节点圆点与错误摘要同步；错误入口定位字段；草稿不被视为正在执行 |
| EX05 | 新建实验；记录运行、异常、重试、完成；发布结论 | 样本、设备、SOP 与证据保存到本次记录；前置未完成不能越级；重试保留历史 |
| EX06 | 证据不足时发布结论；导出；重载 | 必需结论和证据缺失会阻止保存；有结论后卡片、详情、导出与工作台一致 |

## 共享、项目副本与资源

| 编号 | 操作路径 | 预期与数据核对 |
| --- | --- | --- |
| SH01 | 进入我创建和他人创建的两个共享项目 | 身份、权限及申请方向一致，不依靠角色演示控件 |
| SH02 | 现有项目转共享；新建空白共享；选择共享内容 | 保留源项目身份，所选版本进入共享；科研对话和未选内容不共享；重复转换受限 |
| SH03 | 遍历知识库、工具、实验；选择每条资产 | 类型化预览与所选版本一致，不能把知识引用误当实际文件下载 |
| SH04 | 切换两种工作流；点击全部有效节点 | 数据集、训练、评测、推理及实验结论关系对应资产版本；同一数据集复用只显示一个源节点 |
| SH05 | 缩放、适应、平移；打开和关闭节点抽屉 | 节点详情对应所点资产；关闭后保留画布位置，抽屉滚动不带动画布 |
| SH06 | 邀请、取消、接受、改角色、移除、转交 | 取消不写入；受邀与活跃区分；所有者保护有效，查看者不能执行管理动作 |
| SH07 | 他人申请我的资产；我批准或拒绝 | 申请记录绑定申请人、来源资产版本和目标项目；拒绝原因必填；只影响对应申请 |
| SH08 | 我向他人申请；撤回；批准后导入；重复导入 | 待审批不可导入；导入为独立副本，保留来源与版本；不能覆盖源资产或重复导入 |
| SH09 | 发布新版本；移除成员；检查此前已导入副本 | 旧版本与已审批记录不变；未批准申请按权限撤回，先前独立副本保留 |
| PJ01 | 创建项目副本，选择复制范围；取消和确认 | 新项目有新 ID；只复制选择的内容，不复制私人对话或共享成员权限 |
| RS01 | 上传工具文件／文件夹；无 SKILL.md；有效重传 | 格式错误具体；文件内容不执行；解析元数据只填未手动修改字段 |
| RS02 | 上传 CSV、JSON、FASTA 等；表头／格式错误；外部来源 | 输入校验与预览相符；错误不伪装成上传成功；来源地址只允许有效 HTTPS |
| RS03 | 选择六个标签；清除并重新上传同一文件 | 最多五个，勾选状态与数据一致；重新上传触发检查，旧文件不残留 |
| RS04 | 保存草稿、私有创建、公开提交、撤回、拒绝、通过 | 可见性、审核状态与入口一致；待审核内容不进入公共精选 |
| RS05 | 修改已发布资源；选择旧版本；下载文件 | 新版本递增且旧版本不变；下载文件与所选版本一致 |

## 跨页面组件与滚动

| 编号 | 操作路径 | 预期 |
| --- | --- | --- |
| UI01 | 对照项目管理检查新增页标题、按钮、卡片、图标 | 同级尺度、圆角、线宽、主次操作、配色和命名一致 |
| UI02 | 鼠标 hover、键盘 Tab／方向键／Esc、触屏 | hover 不改变状态语义；焦点可见，菜单可退出；触屏操作区可点击 |
| UI03 | 桌面、短屏、窄屏、字体放大、长名称 | 页面无意外横向溢出；名称可识别，任务、标签、查看全部不重叠 |
| UI04 | 分别滚动实验编辑器与定位图 | 只滚动目标区域；页头操作固定，切换节点保留配置 |
| UI05 | 分别滚动共享资产列表与右侧预览 | 滚动互不干扰；新预览从顶部开始，列表不跳回起点 |
| UI06 | 资源表单滚到底部；继续滚动；切换控制字段 | 页头和操作栏固定，字段区独立滚动；取消和提交仍可到达 |
| UI07 | 滚动抽屉和模态窗口；关闭后继续操作 | 不带动背景画布；退出恢复合理焦点；取消不写入数据 |
| UI08 | 浅色与深色主题、错误、空态、禁用态 | 正文与状态可读；异常只用少量语义色；不借颜色替代状态文字 |

执行后报告位于 `work/qa/new-pages-walkthrough/full20/report.html`，额外边界用例见上级目录 `additional-cases.json`。结果以同一构建哈希下的实际运行记录为准，不能用历史通过记录替代本轮执行。
