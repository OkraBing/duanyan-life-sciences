# 工作台三课题概览

2026-11-21，按用户最新要求，以内置 image 模型生成的三课题图稿实现。图稿、提示词与实际截图保存在 `work/design/workbench-structured-20261121/`。先前的双列任务详情稿保留为探索过程，当前页面采用 `three-projects.png`。

| 层级 | 展示与交互 |
| --- | --- |
| 课题进展 | 标题与手动左右箭头。桌面同时显示三个课题，箭头每次移动一个位置；首尾禁用，不自动轮播，不用 A/B/C 编号。 |
| 课题卡 | 仅显示课题名称和进入入口，名称最多两行；各卡标题、分组和边界对齐。 |
| 实验／模型 | 同时显示两个分组及待关注数量。实验标题进入当前课题的实验列表；模型标题进入训练列表，旁侧菜单提供训练、评测、批量和在线推理入口。 |
| 任务行 | 仅保留 16px 线性图标、任务名称、状态。编号、环节、错误详情、方法及进度在任务详情查看。整行可点击和键盘进入，辅助名称保留课题与编号。 |
| 长列表 | 各课题、各分组独立分页；切换课题窗口不清空分页，也不会借用其他课题的列表范围。 |
| 状态 | 普通状态为中性文字，异常保留少量红色；已完成模型标为待查看。任务筛选和结果已读规则沿用工作台关注队列。 |
| 资讯与灵感 | 资讯在较宽的一栏，手动圆点切换；灵感每天一条，保持轻量，不随课题窗口切换。 |

组件沿用现有设计语言：4／8px 间距体系、12px 卡片圆角、16px 卡片内边距、16px 课题标题、13px 任务名、11px 状态文字；使用产品的中性表面、文字、边框、焦点与异常语义色，不新增一套品牌颜色。卡片样式集中在 `src/workbench-project-cards.css`，不影响其他页面的项目卡或任务详情。

按实际可用宽度降为两张或一张课题卡；矮屏减少每组同时展示的任务数量，仍可分页查看全部关注任务。极短屏和触屏允许自然滚动，任务、分页及下方内容不裁切。
