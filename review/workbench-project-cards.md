| 区域 | 展示与交互 |
| --- | --- |
| 左上今日灵感 | 轻渐变横条，只显示小标签、一句完整问题、“换一句”和深底色“去探索”。两个动作同排，刷新为轻量次操作，探索保留主按钮。问题是可选择的普通文本，没有点击操作。 |

| 任务筛选 | 保留关注队列：运行中、异常待处理、完成但尚未查看的任务。已读结果从完整列表查看；重跑和新结果版本重新提示。 |
| 长列表 | 实验、模型任务各显示最多 3 条，不使用组内翻页或滑动。超出部分显示“还有 N 项”；“查看全部”进入相应课题的实验管理或模型制备模块。单条任务可直接进入详情。 |
| 右侧学术资讯 | 常驻“我为你找到可能相关的最新论文”，每页显示 4 张论文卡；左右箭头手动翻页。每张显示标题、研究内容描述、相关课题标签及外链图标。 |
| 论文内容 | 精选论文使用已登记的研究摘要；Crossref 返回的论文优先展示实际摘要，缺失时明确显示摘要缺失。加载失败保留已有论文。标题与描述不承担隐含按钮操作。 |
| 论文筛选 | 新检索结果与已有缓存都经过生命科学标题主题、课题关键词两层筛选；不再因中文课题缺少英文关键词而放行所有结果。旧缓存中的教育、思政等无关论文会被清理。标题规则不能替代原文阅读。 |

组件沿用现有文字、表面、边框、焦点、主按钮和异常语义色。任务图标使用低对比中性底色，普通状态使用中性色，异常仅在小面积文字中使用红色。

桌面常用视口保持一屏；窄屏纵向排列，允许自然滚动。任务行、说明、查看全部和论文外链不得重叠或裁切。样式集中在 `src/workbench-dashboard.css`，渲染与适配在 `src/workbench-dashboard.js`，不更改其他页面的卡片样式。

专项验收：`npm run test:dashboard`。覆盖区域布局、刷新持久化、课题绑定、论文翻页、每组最多三条任务、查看全部的范围、关注摘要、无自动轮播、深浅主题、窄屏及空态。历史读回执与旧缓存升级由 `test:attention` 和 `test:upgrade` 验证。


## 文案策略

这是研究员每天查看课题状态、处理实验与模型结果的工作台。用户已熟悉实验、训练和推理术语，主要在桌面浏览。

- 对象固定称为“课题”“实验”“模型任务”；不按 ABC 编号。
- 任务名负责识别，描述只说明当前环节、结果或异常；状态和进度统一放在标签内。
- 分组入口统一为“查看全部”，直接进入当前课题的完整模块；单条任务打开详情。
- 关注队列沿用运行中、异常、完成未查看的规则，完整历史仍保存在任务模块。

本轮跨页面文案审查见 [新增页面 UX Writer 与体验走查](new-pages-ux-writing.md)，逐项操作步骤见 [新增页面用例](new-pages-test-plan.md)。验收记录见 `new-pages-acceptance.json`。
