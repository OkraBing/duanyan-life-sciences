# 工作台布局与交互

2026-11-21 按最新区域标注调整。标注中的蓝、绿、红用于指定位置；页面延续产品的中性配色，不使用对应的大面积色块。此前三课题图稿是历史设计，当前布局以本说明及实际验收截图为准。

| 区域 | 展示与交互 |
| --- | --- |
| 左上今日灵感 | 轻渐变横条，只显示小标签、一句完整问题、刷新图标和深底色“去探索”。问题是可选择的普通文本，没有点击操作。 |
| 灵感刷新 | 默认每天一条，手动换一个课题相关问题后在当天保留；异步加载项目期间不覆盖持久化问题。当前采用已有课题问题池，没有接入新的生成服务。 |
| 去探索 | 打开科研对话，绑定问题所属课题并预填输入框，用户可以编辑或发送；不会自动发送。 |
| 左下实验进展 | 动态关注摘要、课题窗口、实验和模型两个任务分组。窗口按实际可用宽度显示一至三张课题卡；左右手动移动，首尾禁用。 |
| 任务行 | 类型图标、名称、状态、简短说明、样本或训练进度上下文。异常原因、当前环节、训练目标均取自对应任务。长说明单行省略，可在详情查看。 |
| 任务筛选 | 保留关注队列：运行中、异常待处理、完成但尚未查看的任务。已读结果从完整列表查看；重跑和新结果版本重新提示。 |
| 长列表 | 各课题及分组独立分页；每页数量随可用高度变化。完整列表入口保留当前课题范围。 |
| 右侧学术资讯 | 常驻“我为你找到可能相关的最新论文”，下方同时显示多张论文卡；左右箭头手动翻页。每张显示标题、研究内容描述、相关课题标签及外链图标。 |
| 论文内容 | 精选论文使用已登记的研究摘要；Crossref 返回的论文优先展示实际摘要，缺失时明确显示摘要缺失。加载失败保留已有论文。标题与描述不承担隐含按钮操作。 |

组件沿用现有文字、表面、边框、焦点、主按钮和异常语义色。任务图标使用低对比中性底色，普通状态使用中性色，异常仅在小面积文字中使用红色。

桌面常用视口保持一屏；窄屏纵向排列，允许自然滚动。任务行、说明、分页和论文外链不得重叠或裁切。样式集中在 `src/workbench-dashboard.css`，渲染与适配在 `src/workbench-dashboard.js`，不更改其他页面的卡片样式。

专项验收：`npm run test:dashboard`。覆盖区域布局、刷新持久化、课题绑定、论文和任务分页、关注摘要、无自动轮播、深浅主题、窄屏及空态。历史读回执与旧缓存升级由 `test:attention` 和 `test:upgrade` 验证。
