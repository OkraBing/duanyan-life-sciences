## 共享项目的体验路径与数据流

| 路径 | 用户操作与反馈 | 保存或产生的数据 |
| --- | --- | --- |
| 现有课题开启共享 | 项目详情点“分享”，打开成员管理；项目列表出现共享标识 | 保留原课题 ID，新建共享空间，固定资产快照；私人对话不进入共享 |
| 新建共享项目 | 选择已有项目或空白项目，填写名称，选择共享内容 | 空白项目新建课题来源与共享空间；已有项目仅创建共享关系，不搬走原资产 |
| 邀请与成员管理 | 所有者／管理员登记邀请；成员确认加入，可调整角色或移出 | 成员记录由 invited 变为 active；角色决定可见动作与写入权限；不自动发送邮件 |
| 共享资产版本 | 有发布权限的成员选择现有资产；其他成员看到新增版本 | 快照保存来源、版本、内容指纹和产物关系；新版本不覆盖旧审批引用 |
| 向他人获取 | 查看者点节点，先看摘要，选择个人目标项目并填写理由 | 申请固定源资产 ID、版本、指纹、申请人和目标项目，进入 pending |
| 审批 | 所有者／管理员逐项批准或拒绝；申请人可以撤回自己的待审批项 | 只改变申请状态与审核记录；批准不产生个人副本 |
| 确认导入 | 申请人打开“我的申请”，对待导入项确认导入 | 新资产 ID、独立数据与来源凭据；模型不重训，数据集成为草稿，重复导入被拦截 |
| 移除成员 | 关闭后续访问，撤销其未完成授权，已导入副本保留 | 共享权限和申请记录改变，接收者个人副本不被远程删除 |
| 查看工作流 | 按模型训练／实验验证切换，点节点打开右侧详情 | 画布读取固定版本及明确输入引用；同一版本只画一次，可连接多个实验；缩放和平移不因开抽屉清空 |

当前账号同时拥有一个项目、参与另一个项目。两个项目分别显示“获取申请”和“我的申请”，前者审批他人，后者只能撤回或确认自己的导入。项目资产左侧沿用项目对话的排列逻辑，选择条目后右侧展示类型化详情。

模型关系为数据集 → 模型训练 → 模型评测 → 模型推理；实验关系为样本数据集 → 实验任务 → 实验结论。空位置不制造任务或产物。一份样本数据集复用到多个实验，表示复用样本编号与来源，实际实验分支仍需要独立分样。实验内部的串并行执行关系另存于环节依赖，不能与共享画布的资产来源关系混为一条线。

## 历史模型接入状态（2026-11-14）

以下是上游版本的历史记录。-3 当前保留模型系列接入结构；本轮未复核公网代理和真实调用，不能把下列记录算作本轮验收。本轮将原有单密钥设置断言迁移到当前系列接入界面，保留凭证隔离、持久化、失败和空回复验证。

**统一代理已部署并配置服务端密钥，公开页面固定使用它，访客无需提供 Key。默认模型 `deepseek-flash` 的真实调用已验证。**

代理地址：`https://duanyan-deepseek-proxy.badbotai.chatgpt.site/api/model/chat`。2026-11-14 已从 GitHub Pages 的浏览器环境验证：健康检查返回 200，密钥配置与数据库就绪；连通测试真实返回“收到”，意图分类和课题问答也均返回 HTTP 200。浏览器请求不携带 API 密钥。

`site-config.js` 设置 `managedProxy: true`。它固定对话请求的去向，忽略浏览器里以前保存的直连模式或代理地址；访客仍可选择模型。密钥通过 Sites 服务端 Secret `DEEPSEEK_API_KEY` 配置；以后更换密钥时更新该 Secret 并重新发布代理版本即可，前端不需要改动。`deepseek-v4-pro` 的真实调用未在本次测试中验证。

统一代理限制每 IP 每分钟 10 次、全站每分钟 60 次和每天 1000 次，单次输出最多 900 token。数据库只保存限流计数和每日变化的 IP 哈希标识，不保存对话。详见 [代理说明](proxy/sites/README.md)。

密钥保存在代理服务端，不能提交到仓库、写入 HTML 或 `site-config.js`。公开页面不显示密钥字段、直连开关或可编辑代理地址，也不会读取已存的浏览器密钥来发送请求；已有本机密钥不会被删除。本机代理返回 `managedProxy: false`，保留原有自行配置与浏览器直连选项。
